# StruckBill — Receipt Generator & Print UI

Eksperimen aplikasi frontend untuk membuat **struk belanja sederhana** yang bisa dilihat dan dicetak dari browser, dengan format menyerupai struk ritel.

## Fungsi yang ada

- Form input barang dan pengumpulan item belanja.
- Kalkulasi nilai tiap item dan total pembelian melalui JavaScript.
- Tampilan struk siap cetak dengan **tanggal dan waktu**.
- Tombol cetak yang dapat menggunakan fitur **Print / Save as PDF** bawaan browser.

## Teknologi

**HTML, CSS, dan JavaScript** pada `index.html` dan `script.js`.

## Hasil dan kondisi repository

Hasil utama berupa **simulasi pembuatan struk lokal** untuk kebutuhan latihan manipulasi DOM dan perhitungan pembelian. Tidak ada indikasi integrasi POS, database transaksi, atau printer kasir fisik dari aplikasi utama.

Repository juga berisi `tes.py` (latihan penjumlahan Python), `x.php` (berkas PHP modul profil yang tidak terhubung dengan generator struk), dan folder `.venv/` yang ikut ter-commit. Berkas tambahan itu **bukan bagian dari fitur struk**; folder virtual environment sebaiknya dikeluarkan dari version control dalam pekerjaan pemeliharaan terpisah.
